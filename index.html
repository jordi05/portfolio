01Aplicación web

StudyFlow

Un espacio para organizar horario, entregas y apuntes, con temporizador Pomodoro y personalización de la interfaz.

OrganizaciónInterfaz adaptablePWA
Qué reúne el proyecto +

Acceso con cuenta, navegación lateral, temas y colores configurables. Una aplicación pensada para reunir las tareas de estudio en una sola interfaz.

Proyecto personal con desarrollo asistido por IA. No se presenta como trabajo de clase de DAW.

02Web de divulgación

Modo Incógnito

Una web en castellano para reconocer señales habituales de estafa, con guías, un cuestionario y un comprobador de mensajes.

PrevenciónWeb estáticaPrivacidad
Qué reúne el proyecto +

El comprobador identifica señales de alerta de forma local. No sustituye una verificación de identidad ni garantiza que un mensaje sea seguro.

Proyecto personal con desarrollo asistido por IA. Enlaces y autoría pendientes de revisión antes de publicar.

03Práctica de laboratorio

Laboratorio de auditoría web

Preparación de un entorno virtual con Kali Linux y herramientas para estudiar el tráfico web en un laboratorio controlado.

Kali LinuxVirtualBoxCaido
Ver el caso de estudio +

La memoria entregada incluye capturas de configuración de la máquina virtual y su red, instalación de herramientas y preparación del proxy web.

El objetivo es separar las pruebas del sistema principal y comprender el recorrido de las peticiones HTTP/HTTPS.

Práctica formativa, no una auditoría profesional. Solo en entornos propios o autorizados. La memoria original no se publica.
